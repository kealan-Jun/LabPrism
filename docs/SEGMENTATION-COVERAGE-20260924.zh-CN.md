# 分割数据覆盖与 v6 训练 · 2026-09-24

本轮将实际分割训练集从 1,119 图 / 8,205 个实例扩大到 **4,172 图 / 50,074 个实例**，完成 RTX 3090 Ti 上的 10 轮训练与原图对比。候选尚不适合替换当前 SAM：少数目标改善，移液器和已标语义像素出现回退。

新增的 3,053 张训练候选来自已存在、已完成初标的 NAS 数据。没有新增原始媒体或已复核标签；4,076 张仍为未复核 SAM 伪标签，其余保留既有复核框、选定实例和未知区域的各自状态。原 9 张开发图 / 17 个选定实例不变。沿用已批准的开发素材复用边界，保持隔离来源和质量暂停。

采样器现在保证每轮每张冻结训练图至少使用一次，再追加有权重的回放。实际每轮 6,000 次呈现、375 个完整 batch16，共 60,000 次呈现；每轮日志均确认覆盖 4,172 张。训练耗时 480.13 秒，AMP FP16，峰值已分配显存约 2.11 GiB。继承 v3 分割头并重建 AdamW；708 个原检测参数/状态张量逐字节保持，不是完整恢复优化器。

以上是反复使用的小型开发对照。表中的 SAM 是 LabPrism 逐帧基线 SAM2.1 Tiny，不是 VisionCortex 时序传播使用的 SAM2.1 Base Plus。部分参考标签来自 SAM 辅助草稿，不能当作独立人工真值或完整 AP / 语义 mIoU。训练内部 160 网格 IoU 为 0.72355→0.73134，与原图指标分开。历史 SAM 对照的源码版本不匹配，故本轮重新推理，没有直接沿用旧分数。

短实看原幅 45 秒双手和称量 25 秒帧，以及移液器、离心管、瓶盖裁剪：部分管身轮廓改善，但手套扩入袖口、细长器材边界缺失和漏检仍在。9 张开发图及两张问题帧的新旧检测框、类别、置信度完全一致。两张问题帧已参与训练，不算独立验证。

3,693 / 4,172 张训练图（88.5%）来自同一天；瓶盖占 30,974 / 50,074 个实例。因此图片数增加并不代表实验、视角或难例覆盖充分。继续增加相同数据上的轮次不能替代这些缺口。

**决定：保留当前 SAM，v6 不晋级。** 已上线的检测模型保持第一人称 v8、第三人称精扫 v5m / 粗扫 v2。本轮没有暂停或重启生产分析、采集及 Web。下一步优先让完整视频中的当前检测、时序掩膜和手姿保持版本一致，随后按具体错误补监督。

代码：AnnotationWorkbench 新增覆盖采样器及测试，17 项采样/分割转移检查通过；实际训练入口及依赖的精确源码留有本地快照与 NAS 摘要。AW 尚无 Git remote，其余既有未提交工作保持；不声称完整训练器已推送 GitHub。首轮冻结和父模型路径预检查失败均保留，之后修复并完成，未绕过原曝光验证或模型哈希检查。
