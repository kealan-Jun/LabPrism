# 当前检测版本的后续推理 · 2026-09-24

当前线上检测已接入两组新的完整视频回放：第一人称 v8 驱动 CUDA 手姿，第三人称 v5m 驱动 VisionCortex 官方 SAM2 时序传播。旧结果保留为历史对照，没有把旧检测的掩膜或手姿直接贴到新框上。本轮是推理集成，不是新增手姿训练或生产手姿晋级。

| 当前回放 | 实际结果 | 耗时范围 |
| --- | --- | --- |
| 第一人称 v8，152 秒 | 761 采样帧、10,817 个检测提议 | 6.65 秒，解码/加载/检测/映射 |
| 同一 RTMPose 候选，CUDA | 601 / 761 帧有手姿，1,063 组接受输出 | 63.10 秒，解码/手姿；不含检测 |
| 第三人称 v5m + SAM2.1 Base Plus | 667 帧、14 窗口、5,336 个掩膜观察；空掩膜 0 | 250.23 秒，加载/JPEG 解码/传播/保存 |

耗时不是完整产品延迟，也不是独占 GPU 吞吐。第一人称 ONNX 使用实际 CUDAExecutionProvider，拒绝静默 CPU 回退；第三人称复用上游 BF16 视频预测器。第三人称完整推理使用已验收的原 v5m 检测结果，所有源像素/时间和版本保持。

旧检测加同一手姿权重有 244 帧 / 311 组输出；新检测链路为 601 帧 / 1,063 组。25、45、65 秒的选定帧由 0 组变为 2 组，但实看仍有明显关节错位、拳形和双手遮挡错误。**输出覆盖增加不等于手姿准确率提高**，当前手姿候选不晋级。以上素材含训练曝光，不能作为独立泛化成绩。

第三人称每窗仍最多 8 个提示，身份每 50 个采样帧重置。14 窗口的起点类别歧义由旧 v2 的 6 组变为 v5m 的 3 组；这是提议统计，不是分类正确率。10、50、80、130 秒实际查看中，所选器材有连续轮廓；未选择器材、手部、透明边界和遮挡仍有限制，不能称全部物体已分割或跨视角身份已建立。

## 接口与真实状态

新增兼容的 `trained-hand-replay/2`：当前检测运行与手姿模型来源分别按哈希核验，并要求同一源视频及每个采样帧的 PTS、时间基和像素一致。手姿只对当前检测框重新计算；不会带入旧实例身份、轨迹或事件。旧版请求保持原要求。

当前第一人称独立检测回放未运行跟踪，关系/事件明确为 `not_run`，不把零事件当作分析成功。原 761 帧的检测字段、源时间和像素摘要全部保持，新手姿的 `source_object_id` 均指向当前实例。为纠正未运行跟踪的描述字段，最终手姿回放重算一次；两次的检测、手姿、拒绝输出、关系及可用性逐项完全相同，原记录保留。

45 项推理/来源检查、13 项网页数据投影检查、13 项展示规则检查、Ruff 及项目检查通过。浏览器检查发现来源摘要被投影遗漏，已修复，只公开来源回执哈希，仍排除私有路径。数据、预测、截图与原始日志在 NAS，权重和源码快照在本地。生产分析、采集和 Web 本轮未重启；只更新本地 8031 检查页的结果包。实际浏览器通过新模型身份、原画/图层、同时间新旧对照、播放/逐帧/跳转及390px无横向溢出检查，无页面异常。
