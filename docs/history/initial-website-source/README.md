# 实验视觉独立官网预览

用户确认同时建设完整官网和实验视觉算法系统。本目录负责独立官网的静态源代码，不修改标注操作或消费项目。

现有页面：`index.html` 首页、`technology.html` 技术页、`demo.html` 演示空间；支持窄屏、键盘页签与图片放大。

当前为本地设计预览 v0.1。品牌“实验视觉 / LAB VISION”为项目工作名称；没有公开发布。首页与演示页使用工作台自有原始实验图片，新模型的推理结果尚未接入。页面不包含模拟检测框、mask、骨架或虚构性能数字。

图像不放入 Git。预览将代码复制到工作台 authoring 下的独立发布目录，并将经过哈希验证的自有图片保存到该目录 `assets/lab-scene.png`。媒体来源和身份写入预览回执。

使用 Python 标准库将独立预览目录绑定到 `127.0.0.1` 提供访问；不得将数据库、NAS 根目录或整个工作台数据根作为网站目录。后续接真实推理结果时保存各模块版本、坐标与时间戳，原始画面与模型输出分别显示。
