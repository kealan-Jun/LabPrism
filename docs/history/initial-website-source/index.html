识别正在使用的器材

02

理解手与器材的关系

将手部姿态、器材轨迹和操作时间关联起来，查看每个动作发生的上下文。

03

回到每个结果的依据

从识别结果、设备读数和操作事件返回原始画面，让观察可以检查与复核。
