# 新视频实际检测、手姿和分割

新视频现在可以从接收的原片回执直接开始检测，无需先制造或重跑一份旧模型结果。
`run_service_detector.py --media` 使用 VisionCortex 当前按角色配置的 TensorRT 模型；
检测结果接 CUDA 手姿和 VisionCortex 官方 SAM2。原生 PTS、采样序号、像素摘要、
视角角色、来源和独立输出状态贯穿各阶段。观察数据 split 保持 null，不自动进入训练。
