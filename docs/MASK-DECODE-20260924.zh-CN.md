# 原图掩膜恢复与实际视频更新 · 2026-09-24

修复联合分割候选的掩膜解码：原实现先把 160×160 的连续输出二值化，再最近邻放大，放大了块状边缘。新实现先按实际 letterbox 恢复连续值、去除 padding、双线性恢复原图尺寸，再按检测框裁剪和二值化。保留旧模式作为可复现对照，未用形态学填充掩盖模型缺失。

同一 v3 权重、640 输入及原图选定标签，平均 mask IoU **0.71494→0.73009**。九个有选定实例的类别均值均未回退；两个单实例略降，最大下降 0.00847。检测类别、框和置信度完全保持。本轮没有新增训练或更换生产 SAM。

## 对照范围

从 AnnotationWorkbench 导出同一冻结开发集的原图 RLE，逐一核验九图的标签版本、内容摘要、角色和分区。17 个选定掩膜是 SAM 辅助的项目视觉复核，不是独立人工真值或全图完整标签。

本次在原图像素、实际输出轮廓上计算 IoU；上轮训练内分数在 160 网格计算，两种分数不可直接混用。SAM 同图、同 640 检测提示下重新运行，原图 IoU 为 0.86266，存在标签生成方式偏向 SAM 的局限。

| 权重与解码 | 选定目标检出 | 原图平均 IoU |
| --- | ---: | ---: |
| v3 / 640 / 旧二值放大 | 15/17 | 0.71494 |
| v3 / 640 / 原图连续值恢复 | 15/17 | 0.73009 |
| v3 / 960 / 原图连续值恢复 | 17/17 | 0.79366 |
| v5 / 640 / 旧二值放大 | 15/17 | 0.71605 |
| v5 / 640 / 原图连续值恢复 | 15/17 | 0.72948 |
| v5 / 960 / 原图连续值恢复 | 17/17 | 0.79043 |
| SAM / 同 640 检测提示 | 15/17 | 0.86266 |

960 输入补回了两个目标，但也改变检测结果，并损害部分烧杯、纸张和试管掩膜；不作为默认更新。维持 v3 权重、640 输入，采用在同类别均值上更好的原图解码。新联合分割仍未超过现用 SAM，不能宣称整体分割模型已经晋级。

实际查看手套、瓶体、密集移液器及试管的原图对照。平滑恢复改善了锯齿边界，模型缺失区域、透明器材和持物遮挡错误仍在；恢复方式不能创造缺失的语义或物理关系。

## 验证及后续集成

原图恢复的孔洞、边界裁剪、空结果、非法尺寸/模式、非有限值及模型角色/哈希检查共四项测试在实际 ML 环境通过。完整视频结果经过生产方文件和消费者结构核验。实际浏览器已通过四选项目录、真实解码方式、播放暂停、逐帧、110秒跨块跳转、定位链接、两片切换、原画/掩膜切换及1440/390宽度检查；无脚本错误和横向溢出。只重启本地LabPrism预览；首次检查发生在启动完成前，另一次检查脚本错误读取了被索引白名单省略的配置字段，改为核验实际帧字段后通过，没有为通过检查改写结果数据。

同时核查 VisionCortex：它已有 `SAM2VideoPredictor` 和固定权重，`temporal_segmentation.py` 对有界关键片段做双向传播。当前回执只保存掩膜面积、边界框和出现比例，不能直接当作可回放的逐帧实例掩膜，也不证明整段身份或动作。后续应扩展这个上游实现的掩膜/逐帧来源交接，避免另造视频传播模型。本轮未修改 VisionCortex 生产配置或服务。
