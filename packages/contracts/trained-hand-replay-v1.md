# Trained hand replay / 1

`labprism-trained-hand-replay/1` consumes an AnnotationWorkbench diagnostic inference artifact. LabPrism does not train or own the dataset. A frozen request pins the parent run's result and receipt hashes, producer training receipt, candidate ONNX, approved parent ONNX identity, label-export identity and normalization pipeline. It binds a known camera role; development replay accepts only train/val sources. Role mismatches, changed artifacts, incomplete training, altered quality hold, automatic promotion, duplicate model IDs or unverified ONNX parity fail closed.

The request accepts verified video-result/3 or /4 with actual per-frame PTS, rational time base and RGB hashes. It preserves the parent's result version; it does not invent missing clocks or upgrade old metadata. Every parent analysis frame must decode with identical dimensions, pixels, PTS and time base. The new model uses the pinned RGB normalization, four real pixel rotations and the existing 0.3 score gate. Low-confidence predictions remain inspectable as rejected proposals. Unknown depth and handedness remain null.

Optional `runtime` selects `{"device":"cpu"}` (the historical default) or `{"device":"cuda","device_id":0,"gpu_memory_limit_mb":1024}`. CUDA reuses the exact rtmlib geometry and SimCC decoder. It requires a working CUDA provider, disables CPU graph assignment and runtime fallback, disables TF32 and bounds the ORT device arena; CUDA context/library allocations are outside that arena budget. Unsupported options and provider failures reject the run. The result records the actual provider, module path, version and GPU. Backend qualification does not promote the candidate weights or establish joint accuracy. A CUDA 12 compatible isolated runtime can be created with `scripts/setup_pose_cuda_runtime.py`; it reads existing dependencies without changing the base or production environment.

Detection, instance/semantic masks and object tracks are reused exactly. Each accepted hand carries its source object's identity or identity abstention. Finger-dependent two-dimensional proximity relations and intervals are recomputed from the new hand estimates. These remain unreviewed geometry, not physical contact or experiment steps. Old result/receipt, hand predictions, environment and timing remain explicit parent evidence.

The output uses the existing inference-run/1 receipt, including the copied `hand-training-receipt.json`, full updated model registry, original media producer receipt, replay request/protocol and a source snapshot frozen before decoding. Code snapshots stay in the local data root's `source-snapshots`; NAS protocols retain their path, archive hash and individual source hashes. Runtime does not need the authoritative annotation database. Inference weights remain role/version-specific and unapproved. Timing covers only decoding, new pose and dependent geometry; reused detector/masks/tracking are excluded, and full-pipeline speed is null. Local website inspection does not grant production promotion or public release.

Entry point: `scripts/run_trained_hand.py --request REQUEST.json --output NEW_DIRECTORY`.
